# 📱 SkillUpPlus 2030+
Aplicativo mobile desenvolvido em React Native com Expo, voltado para aprendizado contínuo e engajamento profissional.

Organiza cursos, exercícios e certificados em uma interface moderna, acessível e inclusiva.

# 🚀 Funcionalidades
- Login seguro com fluxo de autenticação.
- Navegação por abas (Tab Navigator) para acesso rápido às principais áreas:
    - Trilhas de cursos
    - Exercícios práticos
    - Meus Cursos (progresso e certificados)
    - Perfil do usuário
- Design escuro para reduzir fadiga visual e aumentar acessibilidade.
- Botões chamativos para destacar ações importantes.

# 🛠️ Tecnologias utilizadas
- React Native
- Expo
- React Navigation
- Ionicons Icons

# ⚙️ Instalação e execução
- Clone este repositório:
    ```
    https://github.com/CavMCarolina/gsMobile.git
    ```
- Instale as dependências:
    ```
    npm install
    ```
- Inicie o projeto com Expo:
    ```
    npx expo start
    ```
- Escaneie o QR Code com o aplicativo Expo Go no celular.
